Also in this release: boards embedded in pages are draggable in the reader and Studio (Alt+←/→ from the keyboard) and reopening a Done task removes its `done:` date. Results on this host: typecheck pass; 158/158 unit; 46/46 extension-host (new: embedded-board moves, OAuth 2.0); code-server smoke, desktop smoke, `test:embedded-board` (new), `test:api`, `test:workspace`, `test:planner`, `test:rich`, `test:phase04`–`test:phase08` all pass on the renamed VSIX. The VSIX is built by the release workflow from the `v1.0.0` tag, not committed.
