## Visual review

Passing tests is not evidence of visual quality. `scripts/visual-review.mjs` opens the explorer, Studio (top, blocks, tables and task lists), the slash menu, Split, the reader, the dashboard, Code mode, the Page view, the explorer context menu, a newly inserted callout with the bubble menu, the link popover and a 760 px window. Screenshots for the 1.2.0 release are in [`docs/screenshots/redesign`](screenshots/redesign) for Default Dark Modern, Default Light Modern and Default High Contrast; [`docs/screenshots/before`](screenshots/before) keeps the 1.1.2 baseline. Every image was inspected; defects found that way (grey callouts caused by translucent theme tokens, a stale hover card covering the link popover, hidden buttons still visible, missing high-contrast menu selection, misaligned task checkboxes) were fixed before release.

## Harness notes

- Desktop runs must not use viewport emulation: CDP device metrics desynchronise pointer input for Electron's out-of-process webview frames. The smoke script only resizes the code-server page; give `xvfb-run` a real screen size instead.
- Electron's CDP endpoint cannot open browser contexts, so the desktop journey checks the exported static site in a separate headless Chromium.
- Neither journey touches the user's running code-server profile.

Run the 1,000-page extension-host benchmark with:

```sh
WIKI_BENCHMARK=1 WIKI_BENCHMARK_REPORT="$PWD/docs/benchmark-1000.json" xvfb-run -a npm run test:integration
```

### External checking tools

The PDF and EPUB tests use real validators, installed outside the repository in `~/.cache/notespace-tools`: W3C EPUBCheck 5.1.0 (`epubcheck-5.1.0/epubcheck.jar`, needs Java) and `pypdf` in a Python virtual environment (`venv/`). The headless browser for PDF printing is Playwright's Chromium. These are test-time tools only; the extension does not ship or download them.

### Benchmark

`docs/benchmark-1000.json` holds the latest measurement on this host (1,005 pages): open and index 0.9 s, search 1.2 ms, static site 4.1 s, EPUB 4.3 s, PDF 6.1 s.
