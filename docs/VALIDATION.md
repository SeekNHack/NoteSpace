# Verification record — historical 1.0.0

For 1.1.0 checks and measured performance, see [testing.md](testing.md) and [benchmark-1000.json](benchmark-1000.json). The record below describes the earlier release.

NoteSpace 1.0.0 was built and exercised from this checkout on Linux. The repository was initially empty; the agreed product scope is a local Markdown wiki with search, backlinks, preview and export. The implementation also includes page management, templates, diagnostics, graph, rename/refactoring, portable trash and code-server support.

These checks ran on Linux. The CI matrix is configured for VS Code host tests on Linux, macOS and Windows, plus a code-server browser test on Linux, but no hosted CI run has occurred because the repository has no public remote. Remote filesystem providers and reverse proxy deployments were not exercised. The extension uses native URI/filesystem APIs and documents provider/proxy requirements; the tested code-server instance used a loopback HTTP origin.

The VSIX was installed into the code-server instance available in this workspace. Its installed `dist/extension.js` SHA-256 matched the built bundle at verification time. A browser **Developer: Reload Window** can be needed to activate a newly installed extension in an already-open session.
