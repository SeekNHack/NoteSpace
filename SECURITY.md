# Security and privacy

NoteSpace keeps your documentation in local files. It sends **no telemetry** and makes **no network request on its own**. Every feature that reaches the network or starts a process is optional, off or idle until you act, and says what it will do first:

| Feature                                                    | Network / process                                                                                                    | Default                                                                                                                         | Safeguards                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API Playground                                             | HTTP requests to the API you choose                                                                                  | idle until **Send**                                                                                                             | First request to each origin asks for approval; loopback/private/link-local targets (checked after DNS) need a separate approval; cloud metadata services are refused; every POST/PUT/PATCH/DELETE is confirmed; credentials only in VS Code SecretStorage, never in the webview, files or exports; redirects not followed                                                                                                                                                                                                                                                                    |
| API Client and ```http blocks                              | HTTP requests you send from the API Client or a page block                                                           | idle until **Send**                                                                                                             | Trusted workspaces only; TLS always verified (no insecure switch, `-k` in pasted curl is ignored and reported); cloud metadata services refused after DNS and on every redirect; Authorization/Cookie dropped on cross-origin redirects; blocks in pages never send on open or export, ask once per origin and confirm every POST/PUT/PATCH/DELETE; secret variables only in SecretStorage, never in the webview, files, exports, generated code or history; OAuth tokens in memory only; history keeps method, redacted URL, status, time and size (no bodies or headers) and can be cleared |
| Dashboards                                                 | Reads local CSV/TSV/JSON/XLSX files                                                                                  | when a dashboard is open or embedded                                                                                            | Computed in the extension with a formula interpreter (no `eval`); Excel macros and external links are never run or followed; data never sent anywhere; exports contain dashboard data only when the dashboard opts in (`export.snapshots`, `export.tables`); CSV exports neutralise spreadsheet formulas                                                                                                                                                                                                                                                                                      |
| AI assistance                                              | Requests to VS Code language models or a configured OpenAI-compatible endpoint                                       | `notespace.ai.provider: vscode` (nothing is sent until you run an AI command)                                                   | Confirmation naming the model and size; credential-like values redacted; results are diff proposals applied only on request; `off` disables it                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Semantic search                                            | Embedding requests to the endpoint you configure                                                                     | off (`semanticSearch.model` empty)                                                                                              | Consent per endpoint and model, warning for non-local endpoints, redaction, drafts and archived versions skipped, vectors stored in VS Code workspace storage                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Code runner                                                | Runs Python, Node or Bash for a code block                                                                           | off (`codeRunner.enabled: false`)                                                                                               | Trusted workspaces only, confirmation per runtime and session, timeout, output limits; never from the reader or exports                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Python notebook kernel                                     | Runs `python3` for notebook cells; checks `python3 --version` once per session                                       | trusted workspaces only                                                                                                         | Cells run only when you run them                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Page history, Git versions, review authors, outdated pages | Read-only `git` commands (`rev-parse`, `log`, `show`, `status`, `for-each-ref`, `ls-tree`, `config --get user.name`) | when you open history, browse or compare a tag/branch, open the health report with `quality.staleDays`, or add a review comment | Allow-list enforced in code; tag/branch names validated and pinned to a commit; nothing is checked out or written; restore is a normal undoable edit                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| PDF export                                                 | Starts an installed Chromium-based browser headless                                                                  | when you export a PDF                                                                                                           | Local file in, local file out; a temporary profile is deleted afterwards                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| MCP server                                                 | stdio process started by your MCP client                                                                             | never started by NoteSpace                                                                                                      | No network port; read-only unless you choose write access; path, symlink and stale-write checks                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Site analytics (exported site)                             | Page-view beacon from the published site                                                                             | off (`analytics.provider: none`)                                                                                                | Only to the configured endpoint (allowed by the site CSP); path only, no cookies or identifiers, honours Do Not Track and Global Privacy Control                                                                                                                                                                                                                                                                                                                                                                                                                                              |

The Markdown renderer disables raw HTML and remote images. Webviews use nonce-based CSP, scoped local resource roots and typed, validated messages. Notebook HTML outputs are sanitized (no scripts, handlers, iframes, forms or remote resources). Mermaid output is checked for scripts and external references. Exported sites are static, with a restrictive CSP and no inline scripts. YAML alias expansion is disabled.

Generated API reference pages replace only their own marked section, and only when it is unchanged since generation; edited sections are a conflict you resolve, and files without markers are never replaced.

Wiki management separates **Remove Wiki from NoteSpace** (hides a wiki in this workspace, touches no file) from **Delete Wiki Files…**, which requires typing the wiki name, accepts only a verified wiki root (never a whole workspace folder, never a root containing another wiki, never through a symlink), asks before discarding unsaved pages, moves files to the system Trash when available and reports partial failures.

Workspace mutations validate relative paths and reject reserved portable file names, traversal and symlinked ancestors. Create, rename, restore and import never overwrite. Deletion moves pages to the wiki-local `.notespace-trash`. Exports go to new directories and are removed again on failure. Symbolic-link checks are not an OS-level sandbox against another process changing files concurrently; VS Code and its filesystem providers remain the security boundary.

Restricted Mode is supported: features that execute code (code runner, notebook kernel) and API Playground, API Client and ```http block requests are disabled in untrusted workspaces; dashboards, search and exports, which execute nothing, keep working. Do not put secrets in pages you export or publish; exports include the indexed text of the exported pages (drafts, daily notes and the planner inbox are excluded unless you opt in).

To report a vulnerability, use **Report a vulnerability** in the [Security tab](https://github.com/SeekNHack/NoteSpace/security) of the repository (private advisory) instead of a public issue. Include the NoteSpace version, VS Code or code-server version, steps to reproduce and the impact.
